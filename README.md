# Gerenciador de Notas

Um aplicativo web simples para gerenciamento de notas, desenvolvido com React.

## 🚀 Funcionalidades

- Criar novas notas
- Visualizar lista de notas
- Editar notas existentes
- Excluir notas
- Interface intuitiva e responsiva

## 🛠️ Tecnologias Utilizadas

- React 18
- JavaScript
- HTML5
- CSS3
- gh-pages (para deploy)

## 📋 Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

## 🔧 Instalação

1. Clone o repositório:

```bash
git clone https://github.com/leonardomachado30/Manager-Notes-React.git
```

2. Entre no diretório do projeto:

```bash
cd Manager-Notes-React
```

3. Instale as dependências:

```bash
npm install
```

## 🚀 Como Executar

Para iniciar o projeto em modo de desenvolvimento:

```bash
npm start
```

O aplicativo estará disponível em `http://localhost:3000`

## 📦 Build

Para criar uma versão de produção:

```bash
npm run build
```
